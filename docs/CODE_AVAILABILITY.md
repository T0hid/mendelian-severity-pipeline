# Code availability

The [Mendelian severity pipeline](https://github.com/T0hid/mendelian-severity-pipeline) includes the code, trained phenotype scorer, public training inputs and saved study results. See the [reproduction guide](REPRODUCE.md) for the commands used to train the models, run the prenatal analysis and regenerate figures.

The repository includes aggregate prenatal results. Running the cohort analysis requires access to the authorised records.

See [CITATION.cff](../CITATION.cff) for citation details and [Licensing](LICENSING.md) for reuse terms.
