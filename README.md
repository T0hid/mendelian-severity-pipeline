# Mendelian severity pipeline

This repository contains the gene–disease severity benchmark, the disease-level phenotype scorer and the prenatal analysis.

[![Demo](https://github.com/T0hid/mendelian-severity-pipeline/actions/workflows/demo.yml/badge.svg)](https://github.com/T0hid/mendelian-severity-pipeline/actions/workflows/demo.yml)

## Run the demo

Use Python 3.11 in a fresh environment. Run these commands from the repository folder.

```shell
python -m pip install -r requirements.txt
python run.py
```

Open `results/index.html` to view the study figures and download the source tables. The demo scores two synthetic profiles with the trained model and checks the saved benchmark results. See `results/predictions.csv` and `results/verification.json`.

To view a GitHub run, open [Run pipeline demo](https://github.com/T0hid/mendelian-severity-pipeline/actions/workflows/demo.yml) and select a successful run on `main`. Download `severity-demo-results`, extract it and open `index.html`.

## Score HPO profiles

Use [example_profiles.csv](data/example_profiles.csv) as a template. The output includes a severity score on a 0–1 scale, the severity class and the probability of each class.

```shell
python run.py --input profiles.csv --output-dir profile_results
```

## Export figures

```shell
python run.py --figures --output-dir figure_results
```

Open `figure_results/index.html`. The [figure map](docs/OUTPUT_MAP.csv) lists the data and plotting functions for each panel.

## Reproduce the benchmark

```shell
python -m pip install -r src/requirements-full.txt
python run.py --check-inputs
python run.py --benchmark --output-dir benchmark_results
```

The benchmark uses the 5 November 2026 configuration, with 100 gene-block permutations per feature set. For scorer training and the prenatal analysis, see the [reproduction guide](docs/REPRODUCE.md). To rerun the prenatal analysis with the frozen scorer, use `python run.py --prenatal --cohort prenatal_cohort_merged.csv --output-dir prenatal_results` after installing the full requirements.

## Data archive and full workflow

The data archive DOI is [10.5281/zenodo.24026146](https://doi.org/10.5281/zenodo.24026146).
See [input inventory](data/README.md) for sources, reference checksums and missing inputs.
Use Python 3.11.15 and install `requirements.txt` in a fresh virtual environment.
Run all commands from the repository root. Input and output paths can be supplied on the command line.

Run the benchmark first, then train the separate disease-level phenotype scorer, then apply it to the prenatal cohort:

```shell
python run.py --check-inputs
python src/run_study.py benchmark --data-dir data/training --output-dir results/main
python src/run_study.py train-scorer --data-dir data/training --output-dir results/scorer
python src/run_study.py prenatal --cohort prenatal_cohort_merged.csv --model results/scorer/model.pkl --scorer-heldout results/scorer/held_out_test_predictions.csv --output-dir results/prenatal
```

The main pipeline takes about 17.5 hours on one CPU workstation. Scorer training and prenatal analysis times depend on hardware and cohort size; timings have not been measured here.
The benchmark writes tables to `results/main/results`, models to `results/main/models`, and figures under `results/main`.
The scorer writes its model and held-out tables to `results/scorer`. Prenatal statistics and figures go to `results/prenatal`.
Publication figures and the run report are generated by the benchmark after training.

A code licence is pending author selection. MIT is suggested; no licence is granted by this statement.

Earlier versions called `gene_annotations.csv` `final_gnn_dataset.csv`. The bundled archive retains that name; input preparation creates a byte-identical copy under the current name. No graph neural network is used.

## Smoke test and full-run comparison

```shell
python src/severity_pipeline.py --data-dir data/training --output-dir results/smoke-main --smoke-test
python tests/compare_runs.py --previous data/reference --current results
```

The smoke test uses up to 400 pairs, 10 permutations, 50 bootstrap replicates and three split seeds. It includes a disease shared by several genes so that the overlap check is exercised, and uses a smaller search. It does not establish reproduction of full-run results. Use a fresh output folder for every run. Default full-run counts and model settings are unchanged.
The comparison checks every field in the two benchmark tables and prenatal statistics, with exact numeric comparison and the documented label mapping. It exits with a nonzero status for differences or missing files. Full-run target MCC values rounded to three decimals are 0.278, 0.577, 0.681 and 0.721; prenatal Spearman rho rounds to 0.383.

See [cleanup validation and remaining items](docs/CLEANUP_STATUS.md) for the tested scope and full-run limitations.
