# Licensing status

The supplied project did not contain an authorised project-wide software licence. This preparation does not assign the authors' or institution's rights or grant new reuse permissions. The rights holder must select the licence before representing the software as openly licensed. An OSI-approved licence can be added once authorised.

Third-party packages and resources retain their original terms and attribution requirements. HPO, MONDO, ClinGen and other source resources are identified in the manifests/input documentation. A project licence must not be described as relicensing those resources.

Code is available for inspection and reproducibility assessment through the repository. Reuse beyond applicable existing terms requires permission from the rights holder until a project licence is supplied. Licence terms and restrictions belong in the final code-availability statement.
